# 서울 어린이 보행 교통사고 시공간 분석 대시보드

> 2012–2025년 서울 어린이 보행 교통사고의 시간적 변화와 자치구별 차이, 사고 다발지역의 공간적 분포를 탐색하는 **산업데이터시각화 개인 프로젝트**입니다.

[**대시보드 실행하기 (Streamlit)**](https://seoul-child-traffic-dashboard-mvjaz7lchxbvvo4qbhursm.streamlit.app/) · [**GitHub 저장소**](https://github.com/jungnakhyeon/seoul-child-traffic-dashboard)

## 1. 연구 배경과 질문

서울의 어린이 보행 교통사고는 장기적으로 감소하고 있습니다. 그러나 **전체 사고건수의 감소가 모든 자치구에서 동일하게 나타나는지**, **사고가 집중되는 장소의 선정 양상은 어떻게 달라졌는지**는 별도로 살펴볼 필요가 있습니다.

이 대시보드는 다음 질문에 답하기 위해 제작했습니다.

1. 서울 어린이 보행 교통사고는 연도별로 어떻게 변화했으며, 전년 대비 증가한 시기도 있었는가?
2. 사고건수는 어느 자치구에 많이 집중되며, 자치구별 첫해 대비 마지막해 변화율은 어떻게 다른가?
3. 자치구별 사고건수 분포와 중앙값은 시간에 따라 어떻게 달라졌는가?
4. 사고 다발지역은 어디에 위치하며, **다른 연도에도 가까운 위치에서 다시 선정된 기록**이 있는가?

## 2. 데이터 출처 및 분석 범위

모든 사고 데이터의 출처는 **한국도로교통공단 교통사고분석시스템 공개데이터**입니다.

| 데이터 | 원자료 | 주요 항목 | 분석 범위 |
| --- | --- | --- | --- |
| 서울시 및 자치구별 사고 통계 | [지자체별 대상사고 통계](https://opendata.koroad.or.kr/api/selectSttDataSet.do) | 연도, 자치구, 사고건수, 사망자수, 부상자수 | 2010–2025년 중 **어린이보행사고**, 서울 지역 |
| 사고 다발지역 선정 기록 | [보행어린이 교통사고 다발지역](https://opendata.koroad.or.kr/api/selectChildDataSet.do) | 선정 연도, 자치구, 장소, 사고건수, 사상자수, 위도·경도 | 2012–2025년 중 **서울 지역** |

두 데이터의 공통 기간에 맞춰 **대시보드의 기본 분석 기간을 2012–2025년으로 통일**했습니다. 자치구는 서울 25개 구를 대상으로 하며, 사이드바에서 분석 기간·지역·지표(사고건수/부상자수/사망자수)를 바꿀 수 있습니다.

분석용 CSV는 원자료에서 필요한 지역과 항목을 선별·정리한 파일이며, **실시간 교통사고 데이터가 아닙니다.**

## 3. 대시보드 기능과 시각화

**Python + Streamlit + Pandas + Plotly**로 구현하고, **Streamlit Community Cloud**에 배포했습니다.

| 화면 | 시각화 / 기능 | 확인할 수 있는 내용 |
| --- | --- | --- |
| **01 연도별 변화** | 영역그래프, 다발지역 선정 기록 추이, 전년 대비 증감 막대그래프 | 장기 추세와 연도별 변동 |
| **02 지역 비교·분포** | 자치구별 사고건수 막대그래프, 첫해·마지막해 변화율 비교, 자치구×연도 히트맵, 박스플롯 | 지역별 규모·증감률·분포 및 중앙값 |
| **03 사고 다발지역 지도** | 지도 마커와 상세 정보, 서로 다른 연도의 **100m 이내 근접 선정 기록** 탐색 | 사고 다발지역의 공간적 분포 및 가까운 위치의 반복 선정 후보 |
| **04 분석 결과·원자료** | 결과 요약, 집계 검산표, 선택 조건 CSV 다운로드 | 분석 결과 확인 및 데이터 재사용 |

**사용자 입력을 변경하면 주요 지표와 시각화에 동일한 필터가 적용됩니다.** 지도는 마우스 휠 또는 지원되는 터치패드 스크롤로 확대·축소할 수 있습니다.

## 4. 주요 분석 결과 (서울 전체, 사고건수, 2012–2025년)

- **누적 사고건수:** 7,669건
- **연도별 변화:** 2012년 771건 → 2025년 339건 (**약 56.0% 감소**)
- **자치구별 누적 사고건수:** 송파구 553건, 강남구 475건
- **자치구별 연간 사고건수 중앙값:** 2012년 32건 → 2025년 15건
- **사고 다발지역 선정 기록:** 전체 기간 213개

> 위 수치는 대시보드에서 **서울 전체 / 2012–2025년 / 사고건수**를 선택했을 때의 기본 집계값입니다. 기간·자치구·지표 필터에 따라 값은 달라집니다.

## 5. 분석 시 주의사항

- **사고건수와 위험률은 다릅니다.** 자치구별 사고건수는 어린이 인구, 통학량, 보행량 등 노출 수준을 보정하지 않았습니다. 사고건수가 많은 지역을 곧바로 ‘더 위험한 지역’이라고 단정할 수 없습니다.
- **사고 다발지역 213개는 고유 장소 수가 아닙니다.** 각 연도에 선정된 **기록의 합계**이며, 지도 마커는 모든 사고 지점이 아니라 선정된 다발지역의 **대표 좌표**를 표시합니다.
- **근접 재선정 후보는 동일 장소 확정이 아닙니다.** 서로 다른 연도·동일 자치구에서 대표 좌표 간 거리 **100m 이내**인 기록을 탐색용으로 연결합니다. 이는 분석 편의를 위한 거리 기준으로, 공식적인 동일 사고 구역 판정이나 안전시설 개선 효과에 대한 증거가 아닙니다.
- **감소 원인은 특정할 수 없습니다.** 연도별 추이에서 감소가 관찰되더라도 이 자료만으로 교통정책의 효과나 사고 감소의 원인을 인과적으로 판단할 수 없습니다.
- **박스플롯의 관측 단위는 사고 1건이 아닙니다.** 각 연도에서 선택한 **자치구별 집계 사고건수**의 분포를 비교합니다.

## 7. 로컬 실행 (Windows)

Python 3.12 환경을 기준으로 작성한 실행 예시입니다.

```powershell
# 1. 프로젝트 폴더에서 가상환경 생성
py -3.12 -m venv .venv

# 2. 필요한 라이브러리 설치
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 3. 대시보드 실행
.\.venv\Scripts\python.exe -m streamlit run app.py
```

실행 후 브라우저에서 보통 `http://localhost:8501` 주소로 접속할 수 있습니다.

`requirements.txt`에 필요한 패키지:

```text
streamlit>=1.40,<2
pandas>=2.0,<3
plotly>=5.24,<7
```
